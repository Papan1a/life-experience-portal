# Life Experience Discovery Portal

> Это мой первый опыт vibecoding — проект собирается в коллаборации с AI-ассистентом.

Приватный веб-портал для небольшого сообщества друзей. Помогает открывать для себя активности, увлечения и необычный опыт, о которых раньше не задумывался.

## Идея

Люди часто не знают, что существует. Портал показывает возможности — не соревнования, не рейтинги, не геймификация, а вдохновение и исследование.

- **Activity** — *что* попробовать: SUP, гончарное дело, велосипед, фотография, астрономия.
- **Variant** — *как* попробовать иначе: «SUP на закате», «велосипед без навигации», «встретить рассвет с велосипеда».

## Стек

- Java 17, Spring Boot 3.4.4
- PostgreSQL 16 + Flyway-миграции
- Spring Data JDBC, Thymeleaf, Spring Security
- Cloudflare R2 (S3-compatible) для медиа
- Testcontainers для интеграционных тестов

## Доступ

Invite-only — открытой регистрации нет. Пригласительный код переиспользуемый, действует 7 дней.

## Запуск

```bash
docker compose up -d    # Postgres
./mvnw spring-boot:run
```

Приложение поднимается на `http://localhost:8080`.

## Статус

Активная разработка. Это MVP — функциональность и UI развиваются.
