# Issue #16 — Редизайн страницы входа под стилистику портала

## Что нужно

Страница входа сейчас оформлена в **чужой стилистике** (сине-фиолетовый градиент), не соответствующей порталу «Свой Круг» (тёплая зелёная палитра, пиксель-арт-логотип). Привести её к общему стилю.

## Контекст

- Шаблон: [login.html](src/main/resources/templates/login.html) — **не** наследует `_layout` (это публичная страница вне топ-бара/сайдбаров), подключает `main.css` напрямую, использует классы `.auth-page`, `.auth-container`, `.auth-form`, `.alert`, `.btn`.
- Стили авторизации: [main.css:69-100](src/main/resources/static/css/main.css#L69-L100):
  ```css
  .auth-page { ... background: linear-gradient(135deg, #667eea 0%, #764ba2 100%); }  /* чужой сине-фиолетовый */
  .auth-container { background: #fff; border-radius: 12px; box-shadow: 0 10px 40px rgba(0,0,0,0.2); padding: 40px; max-width: 420px; }
  .auth-container h1 { color: var(--color-primary); }
  ```
- Палитра портала — CSS-переменные в `:root` ([main.css:10-47](src/main/resources/static/css/main.css#L10-L47)): `--color-primary #62B53D`, `--color-primary-hover #2E7D32`, `--color-bg #F4F7F1`, шрифты `--font-head: Rubik`, `--font-body: Inter`.
- Логотип портала: `/images/logo.png` (используется в топ-баре).
- Имя бренда: «Свой Круг» (в шаблоне сейчас стоит устаревшее «Life Experience Portal» — заодно исправить на «Свой Круг»).

Та же страница регистрации [register.html](src/main/resources/templates/register.html) использует те же `.auth-*` классы — **правка `.auth-page`/`.auth-container` автоматически применится и к ней** (это плюс: единый стиль входа/регистрации; проверить, что регистрация тоже выглядит хорошо).

## Подход

Минимально — переписать `.auth-*` стили под палитру портала; шаблон трогаем точечно (логотип, бренд).

1. **Фон `.auth-page`:** убрать сине-фиолетовый градиент. Заменить на стиль портала — варианты:
   - сплошной `var(--color-bg)`,
   - или мягкий зелёный градиент в тон (`linear-gradient` из `--color-primary-light`/`--color-bg`).
   Выбрать спокойный, тёплый вариант в зелёной гамме.

2. **Карточка `.auth-container`:** подогнать под язык портала — скругление `var(--radius-lg)`, тень `var(--shadow-lg)`, граница `1px solid var(--color-border)`. Заголовок `h1` уже `--color-primary` — оставить.

3. **Логотип:** добавить в шапку формы `<img src="/images/logo.png">` (как в топ-баре, `image-rendering: pixelated`), чтобы страница входа имела узнаваемый бренд. Заменить текст «Life Experience Portal» → «Свой Круг» в [login.html:6,11](src/main/resources/templates/login.html#L6) (и в `<title>`).

4. **Кнопка/поля:** уже используют `.btn-primary` и `.form-group` — они в палитре портала, менять не нужно. Проверить, что `:focus` поля (сейчас `box-shadow` с синим `rgba(37,99,235,...)` в [main.css:155](src/main/resources/static/css/main.css#L155)) — заменить синий фокус на зелёный `rgba(98,181,61,0.15)` для консистентности (это глобально улучшит и формы профиля).

5. Шрифты подхватятся из `main.css` автоматически (Rubik для заголовков, Inter для текста).

## Узкие места

- **Двойное применение:** `.auth-*` используются и на `register.html`. Это желаемо (единый стиль), но **проверить обе страницы** после правок.
- **Синий focus-ring** (`rgba(37,99,235,...)`) встречается в нескольких местах ([main.css:155](src/main/resources/static/css/main.css#L155), `:186`, `.form-group input:focus`) — если меняешь на зелёный, делай согласованно, это влияет на все формы.
- Логотип — пиксель-арт: задать `image-rendering: pixelated` и разумный размер, чтобы не размывался.
- Не ломать функциональность формы (`name="username"`/`name="password"`, CSRF hidden, сообщения `param.error/logout/registered/expired`).

## Что НЕ трогаем

- Логику аутентификации, Spring Security, имена полей формы.
- Структуру сообщений об ошибках/успехе (только визуально через `.alert-*`).

## Как проверить

1. Страница входа — в зелёной палитре портала, с логотипом «Свой Круг», без сине-фиолетового градиента.
2. Регистрация выглядит согласованно с входом.
3. Вход работает: успешный логин, неверный пароль (`?error`), выход (`?logout`), истечение сессии (`?expired`), после регистрации (`?registered`) — все сообщения отображаются корректно.
4. Поля и кнопка — в стилистике портала, фокус зелёный.
5. Мобильный экран — карточка входа адаптивна (`max-width`, `margin`).
