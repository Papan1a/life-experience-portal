# Issue #10 — Аватар-заглушка при отсутствии фото

## Контекст

В шаблонах уже прописан fallback: `@{/images/default-avatar.svg}`, но файл **не существует**. Браузер получает 404 на картинку и показывает пустое место или сломанный img.

## Файлы

- `src/main/resources/static/images/default-avatar.svg` — **создать новый файл**

## Что сделать

Создать файл `src/main/resources/static/images/default-avatar.svg` с простым SVG-аватаром:

```svg
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 128 128" width="128" height="128">
  <circle cx="64" cy="64" r="64" fill="#e5e7eb"/>
  <circle cx="64" cy="48" r="24" fill="#9ca3af"/>
  <ellipse cx="64" cy="110" rx="38" ry="28" fill="#9ca3af"/>
</svg>
```

Это стандартная серая силуэт-заглушка (кружок головы + плечи). Менять шаблоны **не нужно** — они уже ссылаются на этот путь.

## Проверка

1. Открыть профиль пользователя без аватара
2. Вместо сломанной картинки — серый силуэт
3. Открыть `/profile/edit` — та же заглушка в превью аватара
