# Issue #28 — Карточка активности кликабельна целиком

## Что нужно

На главной странице (каталог) карточка активности сейчас ведёт на страницу активности **только при клике по названию**. Нужно, чтобы переход срабатывал при клике по **любой области карточки** — вся карточка должна быть ссылкой.

## Контекст

Проект — Spring Boot + Thymeleaf + HTMX, статика в `src/main/resources/static/css/main.css`.

- **Шаблон карточки:** `src/main/resources/templates/catalog/index.html`, блок `.card-grid` → `.activity-card` (около строк 39-56).
- **Стили карточки:** `main.css`, классы `.activity-card`, `.activity-card-title`, `.bookmark-star` (около строк 601-631).

Сейчас внутри `.activity-card` лежат:
- **звёздочка избранного** `.bookmark-star` (позиционирована абсолютно в правом верхнем углу),
- иконка категории,
- **ссылка-название** `.activity-card-title` (единственный кликабельный элемент сейчас),
- мета-информация (стоимость, длительность).

## В чём нюанс

Карточка содержит **вложенный интерактивный элемент — звёздочку избранного**. Если просто обернуть всю карточку в одну ссылку, клик по звёздочке тоже будет срабатывать как переход на страницу активности, что неправильно (звёздочка предназначена для своего действия — добавления в избранное).

> Примечание: сейчас звёздочка в каталоге — это просто статичная иконка с подсказкой «добавление доступно на странице активности», без своего обработчика. Но решение должно быть устойчивым: клик по звёздочке **не должен** вызывать переход по карточке, даже если позже у неё появится собственное действие.

Также **нельзя вкладывать интерактивные элементы внутрь ссылки** некорректно с точки зрения HTML (ссылка внутри ссылки, кнопка внутри ссылки — невалидно). Это нужно учесть при выборе подхода.

## Подход (без точной реализации)

Выбери один из корректных вариантов:

1. **Карточка как ссылка, звёздочка выведена «поверх».** Сделать саму карточку ссылкой (или сделать переход по клику), а звёздочку оставить отдельным элементом, который перехватывает свой клик и не даёт ему «всплыть» до карточки (предотвращение всплытия события). При этом звёздочка не должна оказаться вложенной в ссылку как невалидный HTML.

2. **«Растянутая ссылка» (stretched link).** Оставить ссылку-название, но визуально растянуть её активную область на всю карточку через CSS (псевдоэлемент с абсолютным позиционированием, покрывающий карточку; карточке задать `position: relative`, которое у неё уже есть). Звёздочку при этом поднять выше по `z-index`, чтобы она оставалась кликабельной поверх растянутой ссылки. Этот подход часто чище, т.к. не требует JS и не ломает семантику.

Любой вариант должен сохранить:
- существующий `hover`-эффект карточки (подъём + тень),
- работоспособность звёздочки как независимого элемента,
- доступность (карточка остаётся одной осмысленной ссылкой для скринридера, а не дублируется).

## Важно

- Менять только шаблон каталога и CSS. Backend не трогать.
- Не ломай раскладку сетки карточек (`.card-grid`) и адаптивность.
- Не делай карточку кликабельной за счёт JS-обработчика на всём блоке, если это приводит к проблемам с открытием в новой вкладке (средний клик / Ctrl+клик). Предпочтителен вариант с настоящей ссылкой (`<a>`), сохраняющий нативное поведение.
- Курсор над карточкой должен быть `pointer`, чтобы было видно кликабельность.

## Как проверить

1. Запусти приложение, открой каталог (главную).
2. Кликни по разным областям карточки (иконка, пустое место, мета-текст) — каждый раз должен происходить переход на страницу этой активности.
3. Кликни по звёздочке избранного — перехода по карточке **не происходит** (звёздочка ведёт себя как раньше).
4. Проверь Ctrl+клик / средний клик по карточке — должна открыться новая вкладка с активностью (если выбран вариант с настоящей ссылкой).
5. Убедись, что hover-анимация карточки и раскладка сетки не сломались, в т.ч. на узком экране.
