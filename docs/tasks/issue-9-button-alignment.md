# Issue #9 — Выровнять кнопки статусов и «В избранное» по одной высоте

## Что нужно

На странице активности и варианта группа кнопок статусов («✨ Интересно», «🎯 Хочу попробовать», …) и кнопка «🔖 В избранное» должны стоять **на одной горизонтальной линии**. Сейчас они визуально не выровнены.

## Причина (подтверждена по коду — НЕ только `mt-4`)

Прошлая попытка чинить только `mt-4` + `align-items` провалилась, потому что **доминирующий фактор был другим**. В правом блоке обёртки лежит **не только** кнопка «В избранное» (`btn-small`), **но и кнопка жалобы** — а это не маленькая кнопка, а `<div id="report-form">` с `padding: 12px` и фоном ([_report_button.html:3-4](src/main/resources/templates/catalog/_report_button.html#L3)). Этот padded-контейнер выше кнопок статусов, поэтому правый блок не встаёт в одну линию с левым ни при `flex-end`, ни при `center`.

Вторичные факторы (тоже устранить): форма статусов несёт `mt-4` (`margin-top:16px`, [main.css:446](src/main/resources/static/css/main.css#L446)) на [_status_buttons.html](src/main/resources/templates/experience/_status_buttons.html), а обёртка использует `align-items: flex-end`.

## Решение

> ⚠️ **Кнопка жалобы выносится из этого блока целиком** (решение владельца — по смыслу ей здесь не место). Переработка самой жалобы (модальное окно, лимит, resize, хранение) — **отдельная задача #13**, НЕ в рамках #9. В #9 жалобу только **убираем** из блока статусов/избранного; куда она переедет — определяет #13.

После выноса жалобы правый блок = только «В избранное» (`btn-small`), левый = статусы (`btn-small`) — обе группы одной высоты, и выравнивание становится тривиальным.

### Правки (только HTML/CSS)

**1.** В [activity.html:67-81](src/main/resources/templates/catalog/activity.html#L67) и аналогичном блоке [variant.html:47-61](src/main/resources/templates/catalog/variant.html#L47) — **убрать** `th:replace` кнопки жалобы (`~{catalog/_report_button :: reportButton(...)}`) из правого блока. (Куда её поставить — см. #13; если #13 делается следом, согласовать; если #9 раньше — временно убрать с детальной страницы, жалоба не критична для каталога.)

**2.** В [_status_buttons.html](src/main/resources/templates/experience/_status_buttons.html) — удалить `mt-4` из `class` у `<form>` (станет `class="flex gap-2 align-center"`). Вертикальный отступ уже задаёт обёртка через `padding-top: 16px`.

**3.** В обёртке на обеих страницах заменить `align-items: flex-end` на **`align-items: center`**.

## Узкие места

- **Координация с #13.** Если #13 (модалка жалобы) делается одновременно — вынос жалобы из блока делается там, а #9 ограничивается правками 2-3. Если #9 идёт первой — жалобу убрать из блока, не пытаясь сразу встроить новый UI (это #13).
- `_status_buttons.html` используется только на activity/variant (не на `/saved`) — убирать `mt-4` безопасно.
- Правки обёртки делать **одинаково** в обоих файлах.
- После фикса #32 кнопка избранного — это `<form class="bookmark-button">`; на выравнивание не влияет (`btn-small` внутри).

## Что НЕ трогаем

- Backend, контроллеры, HTMX-логику.
- Саму кнопку жалобы и её форму (это #13) — в #9 только убираем её `th:replace` из блока.
- Логику статусов/избранного.

## Как проверить

1. `/activities/{id}` — кнопки статусов и «В избранное» на одной линии, жалобы в этом блоке больше нет.
2. `/activities/{aid}/variants/{vid}` — то же самое.
3. Сузить окно до переноса (`flex-wrap`) — раскладка аккуратная.
4. Поставить/снять статус и закладку — функциональность не сломана.
